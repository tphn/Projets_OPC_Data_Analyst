Projet 03 - Requêtez une base de données avec SQL

Secteur Assurances : veille stratégique

Exemple de requêtes sur la base de données :
- Lister les contrats avec le prix de la cotisation et leur surface pour les appartements
- Lister les numéros de contrats (contrat_ID) avec leur surface pour la commune de Caen.
- Lister les numéros de contrats avec le type de contrat et leur formule pour les maisons du département 71.

Méthode et outils :
- Dictionnaire de données / Excel
- Schéma de la base de données / SQL Power Architect
- Chargement de la base de données / PG Admin 4 & PostgreSQL
- Requêtes / PostgreSQL
