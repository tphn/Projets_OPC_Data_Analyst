Projet 04 - Réalisez une étude de santé publique avec R ou Python

Etude sur l'alimentation dans le monde

Exemple d'analyses :
- Proportion théorique de personnes pouvant être nourries en 2017
- Répartition de la disponibilité intérieure mondiale en 2017 (graphique circulaire)
- Alimentation humaine vs. animale : utilisation des principales céréales (diagramme barres)
- Sous-nutrition en 2017 (diagramme barres horizontales)
- Evolution de l’aide alimentaire entre 2013 et 2016 pour les pays qui en ont le plus bénéficié (diagramme courbes)

Outils :
- VS Code
- Extension Jupyter Notebook
- Python 3.12
- Librairies -> Pandas et Matplotlib.pyplot
