Projet 05 - Créer et utilisez une base de données immobilière avec SQL

Avec vérification de la conformité RGPD

Exemples de requêtes
- Nombre total d’appartements vendus au 1er semestre 2020 (Join, where, groupby)
- Nombre d’appartements vendus au 1er semestre 2020, par région (join, where, groupby, order by)
- Proportion des ventes d’appartements en fonction du nombre de pièces (with, count, join, where, groupby, orderby)

Méthode et outils :
- Dictionnaire de données / Excel
- Nettoyage des données + normalisation 1NF + anonymisation / Excel Power Query
- Schéma de la base de données / SQL Power Architect
- Chargement de la base de données / PG Admin 4 & PostgreSQL
- Requêtes / PostgreSQL
