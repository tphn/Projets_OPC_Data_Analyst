Projet 06 - Optimisez la gestion des données d une boutique avec R ou Python

Exemple d'analyses
- Répartition des prix (boxplot)
- Détection des outliers : par intervalle interquartile et analyse Z-score
- Répartition du CA (diagramme barres horizontales)
- Anlayses 80/20
- Analyse du taux de marge calculé (diagramme barres horizontales)
- Matrice de corrélation

Méthode :

- Nettoyage des tables
   - Remplacement de valeurs
   - Suppression doublons
   - Suppression lignes vides
   - Réduction du nombre de colonnes

-Jointure sur plusieurs tables

Outils :
- VS Code
- Extension Jupyter Notebook
- Python 3.12
- Librairies -> pandas, seaborn, numpy, plotly express, Matplotlib.pyplot
